# VDX PRIVATE HUB

Starter repository for the VDX Luau project.

## Structure
- `loader.lua`: loader entry point
- `version.json`: version metadata
- `core/`: configuration and initialization
- `modules/`: main UI and feature-module placeholders
- `assets/`: theme definitions

This starter contains local UI, camera FOV controls, and session/performance utilities. It has not been verified in Delta Executor. Public repositories expose source code; never commit credentials or tokens. It intentionally excludes cheats that target, reveal, or automate actions against other players in public matches.
